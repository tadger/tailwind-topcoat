# topcoat-dialog

Source: `loops/docs/superpowers/specs/2026-11-18-topcoat-dialog-request.md` (the drum machine's request).
Names are exactly as requested: `topcoat-dialog`, `topcoat-dialog__title`, `topcoat-dialog__body`, `topcoat-dialog__actions`.
A skin on a native `<dialog>`; the app calls `showModal()` and the browser supplies the top layer, focus trap, Escape,
inert page and `::backdrop`. The theme adds no JavaScript.

## Deviations and additions

- **Backdrop** is `var(--tc-backdrop)`, a new token (light `rgba(0,0,0,0.4)`, dark `rgba(0,0,0,0.6)`; utility `bg-topcoat-backdrop`),
  not a `color-mix` of an existing token: dimming has to darken both pages, and mixing with `--tc-text` would lighten a dark page.
  There is no hex. `::backdrop` only sees `--tc-*` variables because browsers now inherit it from the dialog (Chrome 122,
  Firefox 120, Safari 17.4); older browsers fall back to `rgba(0,0,0,0.4)`.
- **Shadow** is a new shared constant `--tc-shadow-float` (utility `shadow-topcoat-float`), now used by both the tooltip and the dialog.
- **`margin: auto`** is set on the dialog. Tailwind's preflight resets `margin` on every element, which cancels the UA's
  `margin: auto` centering; without this a modal sits in the top-left corner. The base rule never sets `display`,
  so a closed dialog stays hidden.
- **Sizes** follow the request literally: title is `--tc-font-size-large` (strong, `--tc-text-strong`, tight leading), body is
  `--tc-font-size`. These are control sizes (14px / 12px on desktop), smaller than the `text-topcoat-title` / `-body` roles; say
  so if the app wants the prose roles instead.
- **Focus:** the dialog itself, when it receives focus (a dialog with no focusable content), shows `--tc-focus-border` with the
  `--tc-focus-ring` glow. Buttons inside keep their own focus styling.
- Not built: `topcoat-button--danger`, as the request says.
